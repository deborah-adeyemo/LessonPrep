How data flows (beginner words)

Type → Save → Dexie store lessons → appears in My Lessons + Home. No account, no server. Versions = named snapshots (draft / final / used) with Restore.

Reflection after teaching ("reached example 3") → Use in next lesson copies it forward. That is the continuity loop.
